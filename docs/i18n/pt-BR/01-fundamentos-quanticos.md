# Módulo 1: Fundamentos Quânticos

Este módulo apresenta os conceitos fundamentais da computação quântica por meio de animações interativas e exemplos práticos.

## O que é um Qubit?

Um bit clássico é 0 ou 1. Um **qubit** pode existir em uma **superposição** de ambos os estados simultaneamente — representado como:

$$|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$$

onde $|\alpha|^2 + |\beta|^2 = 1$.

> **Animação**: Veja a visualização da esfera de Bloch no laboratório para entender como um qubit se move pelos estados de superposição.

## Entrelaçamento

Dois qubits podem ser **entrelaçados** — medir um determina instantaneamente o estado do outro, independentemente da distância.

O estado de Bell é o estado entrelaçado mais simples:

$$|\Phi^+\rangle = \frac{1}{\sqrt{2}}(|00\rangle + |11\rangle)$$
