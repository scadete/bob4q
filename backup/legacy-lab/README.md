# Legacy Lab Archive (Pre-Bob Walkthrough)

This directory contains the archival snapshot of the original bob4q lab files, preserved before the transition to the beginner-friendly IBM Bob Developer Journey.

## Contents
- `notebooks/`: Original 5 notebooks (01-quantum-fundamentals to 05-grover-sat-capstone) and helper libraries (`lib/backend.py`, `lib/visuals.py`).
- `docs/`: Original workshop documentation (`i18n/en` and `i18n/pt-BR`).

## Reason for Archive
Archived to allow developing a new, end-to-end beginner-friendly lab focused on the IBM Bob pair-programming experience and modern Qiskit 1.x/2.0 without losing any prior workshop materials.
